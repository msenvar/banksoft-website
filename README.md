# Banksoft — website redesign

**Test site:** https://msenvar.github.io/banksoft-website/ (TR: https://msenvar.github.io/banksoft-website/tr/) — GitHub Pages, published from the `main` branch root. Push to `main` to update.

Static, dependency-free redesign of banksoft.com.tr in English and Turkish.
Seven pages per language sharing one design system, built from partials with a
small Python script.

## Structure

```
src/pages/*.html         EN page content (one <main> per page; title/description in comments)
src/pages/tr/*.html      TR page content (same ids and structure as EN)
src/partials/            header.html / footer.html (EN), header.tr.html / footer.tr.html (TR)
assets/css/style.css     design system: tokens, components, light + dark theme
assets/js/main.js        progressive enhancement (mobile menu, reveal, count-up, contact form)
assets/img/              photography (Unsplash) + logo.svg, logo-light.svg, favicon.svg
build.py                 assembles ./*.html, ./tr/*.html, sitemap.xml, robots.txt
                         and dist/banksoft-preview.html
dist/banksoft-preview.html  everything inlined (CSS, JS, images once) with hash routing
                         and both languages — for sharing / Artifact preview only
```

Pages: index, solutions, company, news, careers, contact, legal.

## Build & preview

```bash
python3 build.py
python3 -m http.server 8765
# open http://127.0.0.1:8765/index.html  (TR: /tr/index.html)
```

Edit files under `src/` or `assets/`, then re-run `build.py`. The root and
`tr/` HTML files are generated; do not edit them directly.

## Design system (from the Banksoft wordmark)

| Token   | Value     | Role                                       |
|---------|-----------|--------------------------------------------|
| red     | `#CF0D1A` | wordmark red, primary action, ledger rule  |
| ink     | `#101B27` | dark grounds, headings                     |
| slate   | `#3D5164` | tagline colour, secondary text             |
| mist    | `#7B92A8` | muted labels, borders on dark              |
| fog     | `#EEF2F6` | light alternate surface                    |

Type: Instrument Sans (display, 500–700) + Source Sans 3 (body), from Google
Fonts with system fallbacks.

## Logo

`assets/img/logo.svg` is a vector recreation of the original `logo.gif`
(Open Sans SemiBold wordmark in `#CF0D1A`, Open Sans tagline in `#3D5164`),
generated by fontTools from outlines, so it scales cleanly. If the company has
the original vector artwork, drop it in as `logo.svg` / `logo-light.svg`
(same viewBox proportions, ~9.5:1) and rebuild. `favicon.svg` is derived from it.

## Contact form

The form works without a backend: with no endpoint configured it opens the
visitor's mail client addressed to contact@banksoft.com.tr with the fields
pre-filled. To send silently instead, set `data-endpoint` on the `<form>` in
`src/pages/contact.html` and `src/pages/tr/contact.html` to a form service
URL (Formspree, Basin, Netlify Forms, or your own POST handler that returns
2xx). A honeypot field (`website`) is included; the JS drops submissions that
fill it.

## Deployment checklist

- Host the root folder (everything except `src/`, `build.py`, `dist/`) on any
  static host or web server; `sitemap.xml` and `robots.txt` reference
  https://www.banksoft.com.tr — change `SITE` in `build.py` if the domain differs.
- Add server-side redirects from the old `Content.aspx?...` URLs to the new pages.
- Set `data-endpoint` on the contact forms (see above) if mail-client fallback is
  not acceptable.
- Have legal counsel review `legal.html` / `tr/legal.html` (terms, privacy, KVKK).
- News: all items are the real, dated items from the current site (2008–2014).
  The newsroom needs recent entries before launch or the page will read as stale.
- Careers: listings link to real kariyer.net postings found on 2026-09-03 (two
  Yazılım Geliştirme Uzmanı, one İdari İşler Personeli). kariyer.net blocks
  automated checks, so confirm they are still open, and update
  `src/pages/careers.html` + `src/pages/tr/careers.html` when they change.
- Photos are Unsplash-licensed placeholders; replace with Banksoft's own
  building, office and team photography where available.
